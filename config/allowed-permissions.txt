# Every Android permission the installed app may request, one per line.
# The build fails if the APK asks for anything not listed here, so a new
# permission (for example internet access, or seeing every installed app
# through QUERY_ALL_PACKAGES) can never sneak in unnoticed.
#
# Android hands the home app the list of launchable apps on its own, so the
# launcher needs almost nothing.
#
# The status line's [wifi] / [mobile]: whether the phone is on Wi-Fi or mobile
# data. It can't open connections; the app still has no internet permission.
android.permission.ACCESS_NETWORK_STATE
#
# Today's events under the date. Read only, asked for only after you say yes
# to showing them, and with no internet the events can't leave the phone.
android.permission.READ_CALENDAR
#
# The prompt's timer and alarm commands: hands a new timer or alarm to the
# clock app. It can't read or change the alarms already set.
com.android.alarm.permission.SET_ALARM
#
# "2 missed" under Phone: only the number of unseen missed calls, from Newt
# Phone. Signature-level, so Newt Phone grants it only to Newt-signed apps.
io.github.secnewt.dialer.permission.MISSED_CALL_COUNT
#
# "3 unread" under Messages: only the number of unread messages, from Newt
# Messages. Signature-level, so Newt Messages grants it only to Newt-signed apps.
io.github.secnewt.messages.permission.UNREAD_COUNT
#
# The weather by the date: temperatures, conditions and active warnings from
# Newt Weather, which does the fetching. Signature-level, so Newt Weather grants
# it only to Newt-signed apps; no ZIP is shared and Newt Home stays offline.
io.github.secnewt.weather.permission.READ_FORECAST
#
# Private space in All apps: Android grants this only to the default home app.
# Its apps stay hidden while Private space is locked.
android.permission.ACCESS_HIDDEN_PROFILES
#
# Added automatically by AndroidX so the app's own broadcast receivers stay private:
io.github.secnewt.home.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
io.github.secnewt.home.debug.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
